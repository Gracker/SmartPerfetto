Search the selected document knowledge bases (`knowledge_authorization`): background, never trace evidence. Omit `knowledge_base_id` to search every selected one. Each hit has an issued `id` (`kref-…`), `knowledgeBaseId`, `title`, `headingPath`, `relativePath`, `lineRange` and a short `excerpt`; read the whole section with `read_knowledge_section`. `truncated` means the knowledge budget cut the hit list.
